# Indian Tourism Analytics Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze tourism trends across India, providing insights into visitor patterns, tourism revenue, and destination performance.

## Objectives
- Analyze tourism trends and visitor patterns.
- Explore revenue distribution across destinations.
- Identify popular tourist destinations.
- Present key insights through interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## Project Files
- `Indian Tourism Dashborad.pbix` – Power BI dashboard file.
- `Indian Tourism Dataset.csv` – Dataset used for analysis.
- `Image of Dashboard/` – Dashboard screenshots.
